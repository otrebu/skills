# Query and file knowledge

Use the compiled wiki first; return to raw sources where the wiki exposes a gap, ambiguity, contradiction, freshness risk, or provenance question.

## 1. Retrieve sufficient compiled knowledge

Read `index.md`, then search page titles, aliases, body text, and linked evidence for every part of the question. Follow useful inbound and outbound links and inspect operation or source dates when freshness matters. Use the schema's full-text or indexed search at the recorded scale threshold; state any coverage limit when that search is unavailable.

Select a sufficient evidence set, not merely the smallest page set. Return to exact raw locators to verify surprising, consequential, conflicting, or weakly represented claims.

Complete this step when the retrieved pages and evidence records cover every part of the question or make missing coverage explicit.

## 2. Synthesize the answer

Answer from the evidence chain:

- cite the evidence-record anchor or raw locator for every material factual claim; link a topic or synthesis page only as navigation, not as the terminal evidence;
- label inference, interpretation, and recommendation as such;
- show conflicting evidence together rather than collapsing it into false certainty;
- state what the wiki cannot answer and which evidence would close the gap.

Use the output form that best serves the question: prose, comparison, table, chart, deck, or canvas.

Complete this step when each part of the question is answered or marked unknown and every material claim can be traced to exact evidence.

## 3. Compound durable work

Follow the schema's query-filing policy. Keep transient lookups in the conversation. File reusable comparisons, analyses, connections, or theses when the human asks or the recorded policy authorizes it.

Search for overlapping durable work before creating a page. Revise and reconcile an existing synthesis or domain page when it already owns the question; create a new schema-enabled page only when no suitable home exists. Update other affected pages when the query exposes a durable connection, contradiction, or correction.

For filed work, preserve claim-local evidence links, integrate the page into meaningful neighbors, and refresh the shared index. Record consulted evidence, filing disposition, and open gaps in the shared terminal log.

Complete the query when every answer is cited or marked unknown and every authorized durable insight has strengthened the existing graph rather than duplicating it.
