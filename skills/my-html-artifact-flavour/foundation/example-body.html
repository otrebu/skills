Fix the docs site

Before you start. The docs site publishes on every merge to main.

  1. Find the failing job. Open the last pipeline of the docs site.
  2. Run the build locally. 
    npm ci
npm run build -- --strict
  3. Check the result.
    1. Read the output. Look for a line that starts with Broken link.
    2. Fix the link. Change the link in the file that the line names.
  4. Put it back. If the change breaks the build, revert it. 
    git revert --no-edit HEAD
